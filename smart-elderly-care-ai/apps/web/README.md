# 🌐 Smart Elderly Care - Web Dashboard & Portal

Thư mục dành riêng cho việc phát triển ứng dụng Web (Admin Dashboard / Caregiver Portal) của hệ thống Smart Elderly Care AI.

## 📌 Kế hoạch phát triển:
- **Web Portal dành cho Quản trị viên / Bác sĩ / Viện dưỡng lão:** Quản lý toàn bộ thiết bị, camera và hồ sơ người cao tuổi.
- **Giám sát trực tiếp:** Xem đồng thời nhiều luồng camera qua WebRTC / RTSP.
- **Báo cáo & Phân tích sinh hiệu:** Đồ thị sức khỏe trực quan, lịch sử sự cố và báo cáo y tế chi tiết trên màn hình lớn.
